# ⚡ Détection de Fraude Énergétique (STEG Tunisie)

Système d'Intelligence Artificielle pour la détection automatisée des anomalies et fraudes de consommation électrique basé sur les algorithmes de Machine Learning (CatBoost, Random Forest, XGBoost).

## 🚀 Fonctionnalités
- Pipeline de Prétraitement et Feature Engineering (30+ variables)
- Gestion du déséquilibre de classes
- Évaluation et métriques complètes
- Interface Web interactive Streamlit
- Rapports techniques complets et présentations
